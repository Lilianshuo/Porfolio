Modified versions and names
---------------------------
- The Latin files are the Latin-subset builds distributed by the @fontsource-variable packages; the Chinese files are
  subsets made with fontTools (a build script) that keep only the characters used on this site. Subsetting is a
  modification under the OFL; the copyright, trademark and licence fields of each font's name table are retained
  (name IDs 0, 7, 13, 14), and the licence texts are shipped alongside.
- None of these families declares a Reserved Font Name in its licence, so the OFL's modified-name rule is not triggered.
  The CSS family names (“Bricolage V”, “Inter V”, “Noto Sans SC S”, “Noto Sans SC Black S”) are local aliases chosen
  by this site and are not used as font file names.
- The fonts are not sold on their own.
- If text on the site changes, regenerate the Chinese subsets: the build script, then check coverage with
  the coverage checker (reports any character that would fall back to a system font).

Fallbacks
---------
Every font stack ends in system fonts (PingFang SC, Hiragino Sans GB, Microsoft YaHei, Noto Sans CJK SC, system-ui), so
text stays readable if a font file fails to load.
